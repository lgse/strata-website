# Strata website

Website for [Strata](https://github.com/lgse/strata), built with Next.js.

## Run locally

Requires Node.js 24.

```bash
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Deploy

Import this repository into Vercel using the Next.js preset and default settings. For a custom domain, set `NEXT_PUBLIC_SITE_URL` to its HTTPS origin.

Third-party notices are in [`public/licenses`](public/licenses/).
